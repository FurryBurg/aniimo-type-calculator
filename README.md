# 伊莫 Aniimo｜屬性剋制計算器 Type Calculator

一個專為《伊莫 Aniimo》設計的網頁版屬性剋制計算工具。

透過直覺的屬性選擇、隊伍弱點分析、雙屬性比較與互動式屬性關係網，快速了解不同屬性組合的弱點與抗性。

本專案使用 **HTML、CSS、JavaScript** 開發，不需要安裝額外軟體，也不需要後端伺服器，開啟網頁即可使用。

## ✨ 主要功能

### 1. 隊伍屬性配置
- 支援我方與敵方各 4 個隊伍位置。
- 每個位置可設定最多 2 種屬性。
- 即時計算各位置的弱點（Weak）及抗性（Resist）。
- 支援快速清空指定隊伍。
- 自動儲存隊伍配置，重新整理網頁也能保留設定。

### 2. 隊伍分析 Analysis
- 一鍵展開我方與敵方的隊伍分析結果。
- 分別統計 9 種攻擊屬性對隊伍造成弱點或產生抗性的次數。
- Weak 與 Resist 分為兩行顯示。
- 依數量由高至低排序。
- 修改隊伍屬性後立即更新結果。

### 3. 屬性拖曳操作
- 可從網頁上的屬性圖標拖曳至隊伍位置。
- 支援從弱點、抗性、屬性比較表及關係網拖曳。
- 將隊伍中已設定的屬性拖到空白區域，可直接清除。
- 支援屬性位置交換。
- 保留原本點擊選擇屬性的操作方式。

### 4. 屬性研究 Type Explorer
- 提供草、火、電、土、風、水、光、暗、冰共 9 種屬性。
- 選擇主要屬性後，自動列出單屬性與雙屬性組合。
- 比較各組合的弱點與抗性。
- 對雙重弱點及雙重抗性提供特殊標示。

### 5. 互動式屬性關係網
- 以圖形方式呈現攻擊屬性與防禦屬性之間的倍率關係。
- 使用不同線條顏色及粗細區分剋制效果。
- 一般倍率（1×）不顯示倍率標籤，降低視覺干擾。
- 雙屬性圖標可在中心持續公轉，圖案保持正向。
- 切換雙屬性組合時，可延續原本的旋轉進度。

## 🎮 使用方法

1. 在「我方隊伍」或「敵方隊伍」中點擊圓形位置，選擇伊莫屬性。
2. 查看該位置的 Weak 與 Resist 結果。
3. 點擊「分析 Analysis」，比較整支隊伍的弱點與抗性分布。
4. 在「屬性研究 Type Explorer」選擇主屬性，瀏覽不同雙屬性組合。
5. 點擊比較表中的組合，查看右側關係網。
6. 也可以直接把屬性圖標拖曳到隊伍位置，快速完成配置。

## 📊 屬性倍率

目前計算器採用以下倍率規則：

| 效果 | 倍率 |
|---|---:|
| 雙重弱點 | 2.56× |
| 弱點 | 1.6× |
| 一般 | 1× |
| 抗性 | 0.625× |
| 雙重抗性 | 0.390625× |

雙屬性以兩種防禦屬性的倍率相乘進行計算。

**注意：雙屬性倍率相乘為本工具目前採用的計算模型，不代表已獲官方確認。** 如遊戲實際機制不同，應以遊戲內資訊為準。

## 🚀 本機使用與部署

**本機使用**

下載專案後，將 `index.html` 與 `attributes.png` 放在同一個資料夾，直接使用瀏覽器開啟 `index.html`。

**GitHub Pages 部署**

1. 建立 GitHub Repository。
2. 上傳 `index.html`、`attributes.png`。
3. 進入 Repository 的 `Settings` → `Pages`。
4. 在 `Build and deployment` 選擇 `Deploy from a branch`。
5. 選擇 `main` 分支及 `/ (root)`，儲存設定。
6. 等待 GitHub Pages 完成部署，即可透過公開網址使用。
